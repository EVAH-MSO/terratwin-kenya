# 🌍 TerraTwin Kenya

A 3D digital twin of Kenya — an interactive geospatial platform for visualizing counties, infrastructure, and facilities.

## Features

- **3D globe** of Kenya powered by CesiumJS
- **47 counties** with real polygon boundaries
- **290 sub-counties** with names
- **12,245 facilities** (hospitals, schools, police, fire stations)
- **9,729 road segments** with type-based coloring
- **Interactive tools**: search, measure, compare, nearest facility, pins, export, screenshot
- **Dark mode** + **presentation mode**

## Tech Stack

- **Frontend**: Angular 18, CesiumJS, TypeScript
- **Backend**: Python FastAPI, pymssql
- **Database**: Azure SQL (cloud)
- **Data**: OpenStreetMap, HDX Kenya Admin Boundaries
